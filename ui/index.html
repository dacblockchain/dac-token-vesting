2 Deploy factory

The connected account becomes the factory owner. To resume an earlier run, paste its factory address instead of deploying a new one.

3 Create the 7 wallets (empty)

MetaMask asks for one transaction per missing wallet. If you reject or one fails, press the button again: wallets that already exist are skipped.

Renouncing is permanent. It stops anyone from adding more (decoy) wallets to this factory, and existing wallets are unaffected.
